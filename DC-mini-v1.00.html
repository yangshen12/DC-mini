            About [v 1.00.0812]

            DC-mini is an interactive RDC (Residual Dipolar Coupling) analysis tool for small molecules. Load coordinates, define RDCs, run SVD fitting (including Jackknife analysis), and visualize results.

            FAQs

            • What file formats are supported? +
              Coordinates: .xyz, .pdb, .sdf, .mol2
              RDC: NMRPipe format; manual input is also supported
              Project save/load: .json
            • Why are my loaded RDCs in the list highlighted with a yellow background and marked invalid? +
              RDC entries are highlighted in yellow when they are not valid for SVD fitting.
              Common reasons include:
              • One or both atoms are missing from the loaded coordinate file.
              • The distance between the selected atoms is zero or undefined.
              • The atom labels do not match those in the current coordinate file.
              To fix this, verify that your RDC file uses the same residue/atom numbering and naming as your coordinate file, and that all coupled atoms exist in the structure.
            • How do I run a SVD fit? +
              Load a coordinate file.
              Add or load at least 5 valid RDCs.
              Click "Run SVD Fit" in the Project Control panel.
            • What is the Jackknife SVD fit? +
              A statistical method where one coupling is omitted in each iteration to estimate fitting stability and uncertainties in tensor parameters.
              At least 6 seleted valid RDCs required for a Jackknife SVD fit.
            • How can I save my project? +
              Click "Save Project to JSON" in Project Control.
              This stores coordinates, RDC data, fitted tensors, and statistics.
              The saved JSON file can be used to re-load the project in "Load Project .."
            • Can I manually add RDCs? +
              Yes. Select one atom from each list (or a methylene/methyl group with correct C-H selection), enter RDC value and error, and click "+Add This RDC".
            • Can I manually add RDCs for methylene/methyl? +
              Yes. Select one C atom from one list, and multiple H atoms (by holding 'ctrl' key on Windows/Linux, '⌘' on Mac) from the other list, enter RDC value and error, and click "+Add This RDC".
            • Why is my SVD Fit button disabled? +
              Ensure you have at least 5 valid RDCs loaded and selected.
            • How to determine RDC error if not available? +
              If no experimental error is reported, you can estimate it from the data itself.
              Common approaches include:
              • Using the standard deviation of repeated RDC measurements (if available).
              • Assuming a typical RDC uncertainty based on similar experiments (e.g., 0.1–0.2 Hz for high-quality data).

              Keep in mind that the RDC error directly affects the weighting in the SVD fit, the RDC error (±D) is capped between 0.01 - 1 Hz in DC-mini .
            • Why my added RDC error is capped? +
              Keep in mind that the RDC error directly affects the weighting of a given RDC in the SVD fit, the RDC error (±D) is capped between 0.01 - 1 Hz in DC-mini .
